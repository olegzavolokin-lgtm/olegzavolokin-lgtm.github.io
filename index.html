Privacy Policy

Last updated: September 2026

This application uses YouTube Data API v3 to upload videos on behalf of users who explicitly authorize the application.

Data Collection

We do not collect, store, or share any personal data. OAuth tokens are stored locally on the user's device only.

YouTube API Usage

This application accesses YouTube accounts solely to upload video content as authorized by the account owner. We do not read, modify, or delete any data beyond what is necessary for the upload function.

Google API Services

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
